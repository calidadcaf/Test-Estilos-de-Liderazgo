# 🎯 Test de Liderazgo - Estilos DISC

Aplicación web para identificar el estilo de liderazgo basado en la metodología DISC (El Lenguaje de los Colores).

## 📋 Características

- Selección de palabras que definen el perfil del líder
- Cálculo automático del color primario y secundario
- Visualización de resultados con porcentajes
- Guardado automático en Google Sheets
- Diseño responsive para móvil y escritorio

## 🚀 Uso

1. Completa el formulario con tus datos
2. Selecciona al menos 7 palabras que te definan
3. Haz clic en "Calcular mi liderazgo"
4. Revisa tus resultados
5. Guarda para enviar los datos a la base de datos

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript (ES6)
- Google Apps Script (backend)
- Google Sheets (base de datos)

## 📊 Estilos de Liderazgo

| Color | Estilo | Características |
|-------|--------|-----------------|
| 🔴 Rojo | Dominante | Orientado a resultados, directo, decidido |
| 🟡 Amarillo | Influyente | Inspirador, social, entusiasta |
| 🟢 Verde | Estable | Democrático, solidario, paciente |
| 🔵 Azul | Concienzudo | Metódico, analítico, preciso |
